# Fuentes

Notas de viaje del autor, extraídas a texto de sus PDF y documentos, para que
puedan trabajarse desde la nube sin depender de su ordenador.

## Qué es esto y qué no

Es **material de investigación interno**. No es contenido publicable. De aquí
sale la estructura de una guía —lugares, tiempos, aparcamientos, orden del
recorrido— que luego el autor completa y aprueba.

Se subió el texto y no los PDF originales a propósito: un PDF arrastra
metadatos (autor, software, rutas del disco) y este repositorio es público,
con un historial permanente.

## Lo que se eliminó antes de subir

- Un número de teléfono en `rooftop-bangkok.md`, que venía repetido en cada
  línea de un volcado de WhatsApp.
- Un documento de especificaciones de una aplicación de facturación, que se
  coló en la extracción y no tiene nada que ver con este proyecto.

**Nada de finanzas entra aquí.** La carpeta de descargas del autor contiene
extractos bancarios y facturas de clientes; están deliberadamente fuera, y
siguen estándolo.

## Reglas al usar estas notas

1. **No son la guía.** Un fichero de guía en `src/content/guides/` solo se
   rellena con lo que el autor vivió y confirma. Lo que aquí aparece sin
   contrastar se marca `PENDIENTE AUTOR`, nunca se completa con texto
   plausible.
2. **Los enlaces a blogs de terceros que aparezcan son investigación.** No se
   citan, ni se enlazan, ni se copian. Lo dice la regla de contenido del
   proyecto.
3. **Las cuentas de redes de terceros** sirven para localizar un sitio, no
   para enlazarlas desde una guía.
4. **Todo pasa por el visto bueno del autor** antes de publicarse.
